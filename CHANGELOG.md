# Changelog

## [1.0.0] - 2026-09-20

### Added

- Standardized the initial Gitea development package and public GitHub export boundary.
- Set the plugin manifest version to `1.0.0`.

## Unreleased

### Added

- Unified CPU, GPU, memory, temperature, battery, storage, network, per-core, process, and SMART health telemetry in one Omarchy Quickshell widget.
- Added multi-GPU selection with NVIDIA preference in automatic mode.
- Added a full-width popup-open indicator for the multi-metric bar block.
- Added mounted-drive usage rows with used/total space, free space, mount point, and percentage.
- Added mounted-drive usage dials beside the primary CPU, RAM, and GPU gauges.
- Added the supplied full-panel screenshots as the repository preview and screenshot gallery.
- Documented installation through `omarchy plugin add` from the GitHub repository.
- Renamed the plugin identity to `thetxeagle.all-in-one-monitor` to match the repository owner handle.

- Removed redundant CPU Temp and GPU Temp toggle chips from the settings drawer.
